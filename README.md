# Сбор сведений от клиентов ИП «Престиж мебель»

Маленький сайт: форма для пострадавших (данные + документы) и закрытая админка
для организатора с выгрузкой сводной таблицы (CSV для Excel) и архива ZIP
(по папке на каждого человека). Python + Flask + SQLite, без внешних сервисов.

## Запуск

### Вариант 1. Docker (рекомендую)

```bash
cp .env.example .env
nano .env          # задайте ADMIN_PASSWORD, SECRET_KEY, ORGANIZER_NAME, ORGANIZER_CONTACT
docker compose up -d --build
```

Сайт: http://127.0.0.1:8000, админка: http://127.0.0.1:8000/admin

Данные лежат в папке `./data` рядом с `docker-compose.yml` (база `claims.sqlite3`
и папка `uploads`). Обновление кода: `docker compose up -d --build`, данные не теряются.

### Вариант 2. Без Docker (Linux/macOS, Python 3.10+)

```bash
cp .env.example .env && nano .env
./run.sh
```

## Как люди попадут на сайт

По умолчанию сайт открыт только на самом сервере (`127.0.0.1`). Выберите один вариант:

1. **Сервер в интернете с доменом (лучший вариант).** Направьте домен (A-запись) на IP
   сервера, впишите его в `Caddyfile`, в `.env` поставьте `COOKIE_SECURE=1` и
   `BEHIND_PROXY=1`, затем `docker compose --profile https up -d --build`. Caddy сам
   выпустит сертификат HTTPS. Откройте порты 80 и 443.
2. **Домашний сервер без белого IP.** Используйте Cloudflare Tunnel или Tailscale Funnel:
   они дают HTTPS-адрес без проброса портов. Тогда тоже `COOKIE_SECURE=1`, `BEHIND_PROXY=1`.
3. **Только локальная сеть.** В `docker-compose.yml` замените `127.0.0.1:8000:8000`
   на `8000:8000`. Подходит, только если все 20 человек придут к вам лично.

**Не публикуйте сайт по голому http:// в интернет.** ИИН, удостоверения и выписки
будут идти открытым текстом.

## Рассылка

Рассылайте ссылку адресно (в личку), а не в общий чат или соцсети. Если задали
`ACCESS_CODE`, отправляйте код отдельным сообщением. Пример текста:

> Здравствуйте! Собираю сведения от всех, кто внёс оплату ИП «Престиж мебель» и не
> получил мебель или деньги, чтобы вместе подать заявление в полицию и иски о возврате.
> Заполните форму: [ссылка], код: [код]. Понадобятся удостоверение, договор, чеки или
> выписка Kaspi, переписка. Срок до [дата]. Данные видит только организатор и
> передаются только в полицию, суд и адвокату.

## Работа в админке

- **Все анкеты**: список, сумма оплат и ущерба, жёлтым подсвечены повторные ИИН.
- **Анкета**: все поля, файлы, статус (новая, нужны документы, подписал заявление,
  признан потерпевшим, иск подан...) и заметка.
- **Скачать таблицу CSV**: открывается в Excel (разделитель `;`, кодировка UTF-8).
- **Скачать всё ZIP**: сводная таблица + папка на каждого человека с анкетой и файлами.
  Это и есть пакет для адвоката или следователя.
- **Журнал**: входы, просмотры, выгрузки, удаления.
- **Удаление**: если человек отозвал согласие, удалите анкету кнопкой внизу карточки.

## Безопасность и правовые риски

1. **Вы становитесь оператором персональных данных** (Закон РК «О персональных данных
   и их защите»). Форма берёт явное согласие и сохраняет его текст в каждой анкете.
   Используйте данные только для этого дела, удалите их после завершения, не передавайте
   никому, кроме полиции, прокуратуры, суда и вашего адвоката.
2. **Утечка ИИН и удостоверений — ваша ответственность.** Сложный пароль админки
   (от 12 символов, сайт без него не пустит в админку), HTTPS, доступ к серверу только у вас,
   шифрование диска сервера. Выгруженные ZIP не пересылайте через общие чаты.
3. **Резервная копия.** Раз в несколько дней копируйте папку `data` на зашифрованный
   носитель. Без бэкапа сбой диска уничтожит все доказательства.
4. **Не превращайте сайт в публичное обвинение.** Нигде не пишите о Пахомове
   «мошенник», «вор» и т.п., пока нет приговора: это риск иска о защите чести
   и деловой репутации (ст. 143 ГК РК) или преследования за клевету
   (ст. 73-3 КоАП РК) [норма не проверена по актуальной редакции на adilet.zan.kz].
   Тексты сайта специально нейтральные: «внесли оплату и не получили товар или деньги».
   Список участников и суммы не публикуйте.
5. **Сайт закрыт от поисковиков** (`noindex`, `robots.txt`), но это не защита: защита —
   это код доступа и адресная рассылка.
6. Анкета на сайте **не заменяет подпись**: заявление в полицию и иск каждый
   подписывает сам.

## Технические детали

- Файлы: pdf, jpg, png, heic, doc/docx, xls/xlsx, txt, аудио/видео (голосовые), zip.
  До 25 МБ на файл, до 150 МБ на анкету (настраивается в `.env`).
- Хранение: файлы в `data/uploads/<id>/` со случайными именами, не доступны по прямой ссылке,
  выдаются только из админки.
- Защита: CSRF, ограничение частоты отправки формы и попыток входа, проверка
  контрольной суммы ИИН, ловушка для ботов, строгие заголовки безопасности.
- Gunicorn запускается с одним воркером: счётчики попыток входа хранятся в памяти.
  Для 20–50 человек этого хватает с запасом.
